Habit Tracker (Minimalist Web App)
A lightning fast,self contained and minimalist Habit Tracker web application built entirely as a single HTML file. 
Designed with zero external dependencies,it runs instantly in any modern web browser and uses localStorage to securely store your data locally on your device.

✨ Features
Zero Installation/Setup: Everything HTML structure,modern CSS styling and JavaScript logic lives inside a single file. 
Just open it in your browser and start tracking.

Monthly Views & Navigation: Quickly switch between months using the intuitive top tab bar to review past progress or plan ahead.

Interactive Grid & Checkboxes: Clean calendar style matrix where you check off habits day by day. 
Includes full keyboard accessibility (Enter or Space to toggle).

Dynamic Analytics & Visualizations:

Real time progress rings and completion percentages.

SVG powered trend area charts displaying daily consistency.

Weekly overview columns showing per week performance breakdown.

Top 10 Leaderboard: Automatically ranks your best performing habits each month.

Fully Customizable: Easily edit habit names on the fly,adjust monthly individual targets and add or delete habits instantly.

Persistent Local Storage: Your habits and progress are saved automatically in your browser's localStorage.

🚀 Quick Start
Download or copy the code from the repository into a file named index.html.

Double-click the file to open it in any web browser (Chrome,Firefox,Safari,Edge).

Start checking off your daily habits!

🛠️ Tech Stack
HTML5 (Semantic elements & accessible roles)

CSS3 (CSS Custom Properties,Grid,Flexbox,Responsive Design)

Vanilla JavaScript (ES6+,DOM manipulation,Event Delegation,localStorage)
